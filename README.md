# ☕ Starbucks Store Analytics Dashboard

An interactive Power BI dashboard built to analyze Starbucks store operations, sales performance, customer behavior, and product insights.

## 📊 Dashboard Features

- Executive KPI Cards
- Sales Trend Analysis
- Revenue by Category
- Top Performing Products
- Store Performance
- Customer Insights
- Interactive Filters & Slicers
- Dynamic Visualizations

## Tools Used

- Power BI
- SQL
- Power Query
- Excel
- DAX

## Key Insights

- Identified top-performing stores
- Monthly sales trend analysis
- Best-selling products
- Revenue contribution by category
- Customer purchasing behavior
